# Жишээ зураг

`DemoSeeder` эдгээрийг `storage/app/work-photos/<block>/` рүү хуулж, `photos`
хүснэгтэд бүртгэл үүсгэнэ.

**Жинхэнэ зургаар солих:** энэ хавтас доторх файлуудыг өөрийн зургаар сольж,
`php artisan db:seed --class=DemoSeeder` дахин ажиллуул. Seeder нь өргөтгөлөөр
нь биш ХАВТСААР нь уншдаг тул `.jpg`, `.png`, `.webp` аль нь ч болно — зөвхөн
хуучин зургийг нь эхлээд `php artisan demo:purge` хийж цэвэрлэ.
